# Wort für Wort

Application de révision du vocabulaire allemand réalisée avec Node.js, Express et EJS.

## Démarrer

```bash
npm install
npm start
```

Ouvre ensuite <http://localhost:3000>. Pour choisir un autre port, définis la variable d’environnement `PORT`.

Les fiches ajoutées et les photos sont conservées dans le navigateur pendant la session ; elles ne sont pas envoyées au serveur.
